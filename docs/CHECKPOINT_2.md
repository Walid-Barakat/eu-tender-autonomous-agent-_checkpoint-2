# Checkpoint 2 — Tender Intelligence Agent

Checkpoint 2 extends the Checkpoint 1 pipeline (Stages 1–9) with a **deterministic bid-decision engine** (Stage 10): hard eligibility gates, seeded Monte Carlo risk per bid, and an exact portfolio optimiser under budget, team and delivery-capacity constraints. It also adds the Round 2 consulting package.

New muscle: stochastic modelling and optimisation. Nothing in Checkpoint 1 was rewritten; every addition is a new module, endpoint, workflow or document.

## Run it

```bash
python -m pip install -e . langsmith
PYTHONPATH=src pytest -q                                   # 22 passed
PYTHONPATH=src python -m tender_agent.decision_engine.cli \
  --input data/live_run_2026_08_12/stage2_advanced_tenders.json --outlines --output engine_result.json
PYTHONPATH=src:. python evaluation/run_langsmith_experiment.py --offline
PYTHONPATH=src python analysis/roi_model.py
PYTHONPATH=src python ui/export_ui_data.py && python ui/build_console.py   # rebuild the console
python scripts/build_stage_10_decision_engine_workflow.py                  # regenerate Stage 10
```
